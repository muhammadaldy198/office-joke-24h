## The joke

> The office clock is ten minutes fast, which makes it the only thing in this
> building that's ever ahead of schedule.

## Run it

```sh
node --experimental-strip-types main.ts
```

The program writes the joke, exactly one line of 115 characters, to
`/output/entry.txt`. It runs offline and deterministically: two runs produce
byte-identical output.
